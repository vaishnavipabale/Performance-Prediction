About This Project

AI-Based Student Performance Prediction System — Final Year Project

Objective

This project aims to predict a student's academic performance using machine learning by analyzing behavioral and academic indicators such as study hours, attendance, sleep, and tutoring support. The goal is to enable early intervention for at-risk students and provide data-driven, personalized recommendations.

System Architecture

  1. Data Layer — Synthetic dataset of 1,500 student records with 10 behavioral/academic features.
  2. Model Layer — RandomForestRegressor predicts the numeric score; RandomForestClassifier predicts the performance category, both trained with Scikit-learn.
  3. Application Layer — A Flask backend serves predictions through both a web UI and a JSON REST API.
  4. Presentation Layer — A responsive HTML/CSS/JS front-end with live charts (Chart.js) for the model dashboard.

Technology Stack

Python 3
Flask
Scikit-learn
Pandas / NumPy
Chart.js
HTML5 / CSS3

Input Features Used

  • Study Hours per Day
  • Attendance Percentage
  • Previous Exam Score
  • Sleep Hours
  • Extracurricular Activities
  • Internet Access
  • Private Tutoring
  • Parental Education Level
  • Study Environment
  • Daily Screen Time

Limitations & Future Scope

The current model is trained on synthetic data for demonstration; real-world deployment would require actual institutional data with appropriate privacy safeguards. Future improvements could include deep learning models, integration with live LMS/attendance systems, and time-series tracking of a student's progress across multiple terms.
